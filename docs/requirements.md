# 要件定義 — Block Drop

最終更新: 2026-09-08

## 何を作るのか

URLを開くだけで遊べる、Web版の落ちものパズルゲーム。PCとスマートフォンの両方で遊べ、自己ベストがブラウザに残る。1人用。

## 使う人

作者本人と、URLを共有された人。前提知識は不要で、この種のゲームを遊んだことがあれば説明なしで操作できることを目指す。ゲーム機やアプリのインストールは不要。

## MVPの完成条件

これが全部満たされたら MVP は完成とする。

- [ ] 公開URLを開くと盤面が表示され、ブロックが自動で落ちてくる
- [ ] PCで ←→ 移動 / ↑ 回転 / ↓ ソフトドロップ / Space ハードドロップ / C ホールド ができる
- [ ] スマホで 横ドラッグ移動 / タップ回転 / 下フリックでハードドロップ / HOLDボタン ができる
- [ ] 落下位置がゴーストとして予告表示され、次のピースがネクスト欄に見える
- [ ] 壁ぎわ・他ブロックぎわでも SRS の壁蹴りにより回転が成立する
- [ ] 横一列そろうと消え、消した列数に応じたスコアが加算される
- [ ] 10ライン消すごとにレベルが上がり、落下間隔が短くなる
- [ ] ブロックが出せなくなるとゲームオーバーになり、リスタートできる
- [ ] 自己ベストを上回るとハイスコアが更新され、**リロードしても残っている**
- [ ] スマホの画面幅でもレイアウトが崩れず、盤面全体が見える

## 主要な機能

| 機能 | 内容 | 優先度 |
|---|---|---|
| 落下と設置 | 7種のピースが1つずつ落ち、着地するとロックされる | 必須 |
| 移動・回転 | 左右移動、右回転／左回転、SRSの壁蹴り | 必須 |
| ソフト/ハードドロップ | ↓で加速、Spaceで即着地 | 必須 |
| ライン消去とスコア | 1〜4列同時消しに応じた加点 | 必須 |
| レベルと加速 | 10ライン毎にレベルアップ | 必須 |
| ネクスト表示 | 次のピースを1つ先まで表示 | 必須 |
| ホールド | 現在のピースを1つだけ退避、1回の落下につき1度まで | 必須 |
| ゴースト | 落下先を薄く予告 | 必須 |
| ハイスコア保存 | 自己ベスト1件を localStorage に保存 | 必須 |
| ポーズ / リスタート | PCは P / R、スマホはボタン | 必須 |
| タッチ操作 | 横ドラッグ・タップ・下フリック | 必須 |

## MVPに入れないもの

**ここに書いてあるものを実装しはじめたら、それはスコープの拡大である。**

- 対戦、オンラインランキング — サーバーが必要になり、静的サイトで完結しなくなる
- 効果音・BGM — 音の善し悪しは触ってからでないと判断できない。動くものを先に作る
- Tスピン判定とその加点、コンボ／Back-to-Back加点 — 標準的な遊び味には必須でない
- ゲームモード選択（40ラインタイムアタック等） — 基本のループが固まってから
- 見た目のテーマ切り替え、ゲームパッド対応
- リプレイ保存、ハイスコアの複数記録（**自己ベスト1件のみ**）
- ネクストの複数表示（1個のみ）

## 動作環境

- 実行場所: ブラウザ（PC / スマートフォン）
- 配信: GitHub Pages（公開リポジトリ、https）
- 対象ブラウザ: Chrome / Safari の最新版。PCとiOS/Androidの両方
- 開発に必要なもの: Node.js 22、pnpm
- デプロイ: **今回の範囲に含む**（GitHub Actions で自動公開）

## 制約・前提

- 画像・音声の素材を持っていない。**単色の矩形と輪郭線のみで表現する。** 結果として第三者著作物の混入リスクがゼロになる
- リポジトリは公開になるため、秘密情報を含めない（そもそも持たない構成にする）
- 「テトリス」は商標のため、名称・表記に使わない

## こちらで決めた既定値

ユーザーに確認せず決めたもの。**後から変えられるが、根拠を残しておく。**

| 決めたこと | 既定値 | 根拠 | 覆ったときの影響 |
|---|---|---|---|
| 盤面サイズ | 10列 × 20行 | この種のゲームの事実上の標準 | 小（定数1つ） |
| スコア式 | 100 / 300 / 500 / 800 × レベル | 同上。4列同時消しの価値が際立つ | 小 |
| レベルアップ | 10ライン毎 | 同上 | 小 |
| 回転方式 | SRS（壁蹴りあり） | 単純回転だと壁ぎわで回らず「操作が効かない」と感じる | 中（テーブルと判定の書き直し） |
| ピース順 | 7-bag（7種を1巡ずつシャッフル） | 純粋乱数だと同じピースが偏り、理不尽に感じる | 小 |
| ネクスト | 1個 | 依頼に指定がなく、まず最小で | 小 |
| ロックディレイ | 500ms / リセット上限15回 | 着地直後の微調整を許すため。無いと窮屈に感じる | 小（定数） |
| キーリピート | DAS 167ms / ARR 33ms | 長押し移動の効き。体感で調整する前提 | 小（定数） |
| ハイスコア保存先 | localStorage キー `blockdrop.highscore` | サーバー不要 | 小 |
| 名称 | Block Drop | 商標を避けた仮称 | 小 |
